# User guide

## Exploring

1. Choose a variable: **`1`** CO₂ (organ), **`2`** Temperature (trumpet), **`3`** Elevation (flute). The voice says its name and a low-to-high sweep shows the pitch direction.
2. **Touch the map with your index finger.** The instrument starts and follows the value under your finger: lower pitch = lower value.
3. Rest your finger on a place: the voice says its name (for example, *"Indian Ocean"*).
4. Press **`i`** to hear the place and the exact value (for example, *"Africa. Temperature: 31 degrees Celsius"*).

## All keys

| Key | Action |
|---|---|
| `1` `2` `3` | Select variable |
| `i` | Say place and value |
| `s` | Mute / unmute |
| `v` | Screen view: camera / NASA data / blend |
| `g` | Globe follows the finger |
| `d` | Show region outlines (debug) |
| `L` | Language: English ⇄ Spanish |
| `c` | Calibration (4 corners + 17 points) |
| `t` | Rotate camera 90° (recalibrate afterwards) |
| `q` / `Esc` | Quit |

## Accessibility notes

- Every action has audio feedback, so the screen is optional.
- Each variable has its own timbre, so you always know which one you are hearing.
- The sound never cuts out while you explore, and the voice is mixed on top of it.
- For a blind user, a sighted helper only needs to start the app and calibrate once.
